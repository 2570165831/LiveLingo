# 隐私边界 / Privacy boundaries

苹果初译会把预览文字交给 macOS 的翻译框架；语言准备由系统管理，未安装的语言可能需要下载。本仓库没有验证系统内部的通信或留存，因此本机模型处理不代表整个应用在所有情况下都完全离线。点击“复制译文”会把译文写入系统全局剪贴板，具备访问能力的其他应用或剪贴板管理器可能读取它，跨设备传播取决于通用剪贴板等系统设置。保存或导出到共享、同步目录后，内容还受对应服务的访问规则影响。开发工具的报告默认输出汇总，报告与测试工件中的正文需显式开启；生成过程的私有模型状态仍可能含正文。权限限制不能阻止当前用户自己的同步软件。恢复副本与模型状态应保留在私有位置，交付前检查最终包。

Apple preview translation passes preview text to the macOS translation framework. Language preparation is managed by the system and may require a download when a language is not installed. This repository has not verified the system's internal communication or retention, so local model processing does not establish that the entire app is always completely offline. Clicking “Copy translation” writes the translation to the global system clipboard; other apps or clipboard managers with access may read it, and cross-device transfer depends on system settings such as Universal Clipboard. Saved or exported content in shared or synced folders is also subject to that service's access rules. Developer reports contain summaries by default; content in reports and test artifacts requires explicit opt-in, while private generation state may still contain prompts and outputs. File permissions do not prevent the current user's own sync software from copying it. Recovery copies and model state should remain private; inspect the final package before sharing it.
