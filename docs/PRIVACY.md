# 隐私边界 / Privacy boundaries

苹果初译会把预览文字交给 macOS 的翻译框架；语言准备由系统管理，未安装的语言可能需要下载。本仓库没有验证系统内部的通信或留存，因此本机模型处理不代表整个应用在所有情况下都完全离线。点击“复制译文”会把译文写入系统全局剪贴板，具备访问能力的其他应用或剪贴板管理器可能读取它，跨设备传播取决于通用剪贴板等系统设置。保存或导出到共享、同步目录后，内容还受对应服务的访问规则影响。质量、benchmark、验收、校准和评分报告默认输出汇总，正文需显式开启。CLI 译文、恢复录音、scoreboard 私有原始证据及模型状态仍可能默认包含正文；其中 scoreboard 的 `.translation-content` 输入和输出不由报告的正文开关控制。在文件系统支持时，新建私有对象限制权限并清除继承 ACL；保存和导出的权限、ACL 保留为尽力而为，不因卷不支持这些属性而拒绝保存。工具不修改已有对象的权限。权限限制不能阻止当前用户自己的同步软件。恢复副本与模型状态应保留在私有位置，交付前检查最终包。

Apple preview translation passes preview text to the macOS translation framework. Language preparation is managed by the system and may require a download when a language is not installed. This repository has not verified the system's internal communication or retention, so local model processing does not establish that the entire app is always completely offline. Clicking “Copy translation” writes the translation to the global system clipboard; other apps or clipboard managers with access may read it, and cross-device transfer depends on system settings such as Universal Clipboard. Saved or exported content in shared or synced folders is also subject to that service's access rules. Quality, benchmark, acceptance, calibration and scoring reports contain summaries by default and require explicit opt-in for content. CLI translations, recovered recordings, private scoreboard evidence and model state may still contain content by default; scoreboard's `.translation-content` inputs and outputs are independent of report content switches. Where supported, newly created private objects restrict permissions and remove inherited ACLs. Saving and exporting preserve permissions and ACLs on a best-effort basis and do not fail merely because the volume lacks these attributes. Tools do not change permissions on existing objects. File permissions do not prevent the current user's own sync software from copying it. Recovery copies and model state should remain private; inspect the final package before sharing it.


## 已知限制 / Known limitations

- 同一用户下的恶意程序仍可能在创建目录与绑定目录、末次身份/权限检查与替换之间抢换对象。R01（新目录）、R04（暂存清理）、R05（保存替换）、R07（恢复副本）和 R08（checkpoint）的这些竞态残余本轮未增加复杂防护；普通静态软链接、非普通文件和已知身份变化的检查仍保留。Python 生产 checkpoint 序列化绑定已打开的文件描述符，但末次检查到 `os.replace` 之间仍有竞态，兼容的文件名回调接口也仍有路径竞态。这些措施不能隔离持有同一用户权限的恶意程序。
- exFAT/FAT32、部分网络卷及外接盘可能不支持 Unix 权限、ACL、硬链接或扩展 rename 原语。保存会尽力保留权限、使用同目录普通 rename 回退；这不保证这些卷上的文件仅当前用户可读，也不保证并发替换具有 APFS 的全部检查和回滚能力。用户主动共享或同步目录仍服从该服务的规则。
- 退出只限制没有实际存储进展的等待；已经运行的课程保存和导出可以报告成功写入的字节并延长等待。普通停止不使用退出截止。清理真正挂起或失败时，可明确选择“仍要退出”：保留已经写到磁盘的文件，尚未写入的进度可能丢失，未清完的暂存文件以后重试。同步内核 I/O 若阻塞主线程，计时器不能保证界面按固定时长响应。
- P09：系统初译仍未增加统一的离线门槛。macOS 翻译框架管理语言包准备，可能需要下载；系统内部通信和留存没有在本仓库得到验证。
- P10：复制译文仍使用系统全局剪贴板，其他具备访问能力的软件可能读取它，通用剪贴板设置还可能使它跨设备传播。
- 正常资源支持限于格式可识别的 `py.typed`、非执行型相对路径 `.pth`、公有证书 PEM，以及资源目录或 `.lproj` 中的 OpenStep `.strings`。未知二进制、执行型 `.pth`、私钥和有重复键的元数据仍被拒绝。导出中的旧诊断只按已知完整失败模板或明确诊断标记过滤，不把任意冒号建议当作失败，也不清理历史原件。

Same-user attackers may still race directory creation/binding or the final identity/permission check and replacement in R01/R04/R05/R07/R08. Production Python checkpoint serialization is descriptor-bound, but the final check/`os.replace` race and the compatibility filename-callback race remain. Filesystem permissions and ACL preservation are best effort on unsupported volumes; ordinary rename fallback does not provide every APFS check or rollback guarantee. Exit deadlines cover inactivity rather than progressing writes. Explicitly quitting after a hang preserves existing disk files but can lose unwritten progress; synchronous kernel I/O can still delay the UI. P09 (system preview translation without a uniform offline gate) and P10 (global clipboard) remain unchanged.
