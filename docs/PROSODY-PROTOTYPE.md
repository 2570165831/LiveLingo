# 离线强调 / 语速原型

`Scripts/prosody_emphasis.py` 只做 CPU 声学计算，不接入 App，不加载 ASR、语言或分类模型，不下载或安装依赖。分数描述可观察的声音突出程度和语速相对偏离，不输出人的情绪、意图或教学重要性标签。

## 输入与运行

输入音频必须已经是 **16 kHz、单声道**，不自动重采样。分段 JSON 可以是数组或 `{"segments": [...]}`；JSONL 每行一个分段。起止时间为音频绝对秒数：

```json
{"start_s": 0, "end_s": 4, "speaker": "lecturer", "word_count": 12}
```

也接受 App 的 `startTime` / `endTime` / `english` 字段，以及公开实验的 `start_s` / `end_s` / `pk_word_count`。可选 `words` 是 `{"start": 0.1, "end": 0.3}` 对象的数组，时间同样是绝对秒数，词不可重叠或超出所属段。单段最长 60 秒，以限制临时分析矩阵内存；更长区间须先拆段。外部 Parakeet 结果必须先把词时间戳投影为这种格式；不得把 token 当作单词。

优先用词时间戳的词数，其次显式词数，最后按文本计数。中文文本使用字符数代理并标成 `characters`，不会与 `words` 合用语速基线；混合文字的计数仍是近似值。无词数或 ASR 明确拒绝时语速为空，不按零词处理。

```sh
python3 -B Scripts/prosody_emphasis.py \
  --audio public-lecture-16k.wav --segments public-segments.jsonl \
  --output new-results
python3 -B Scripts/plot_prosody_emphasis.py \
  --vectors new-results/vectors.csv --output new-results/distribution.png
python3 -B -m unittest discover -s Scripts -p 'test_prosody_emphasis.py' -v
```

使用环境已有的兼容 Python 和依赖。不要为运行这个实验修改或重签 App 内解释器、动态库或扩展；实验运行可用外部 Python 3.13 加载现有打包依赖。用 `PYTHONDONTWRITEBYTECODE=1` 避免向依赖目录写入字节码，将 `NUMBA_CACHE_DIR`、`MPLCONFIGDIR` 和测试用 `PROSODY_TEST_OUTPUT_ROOT` 指向实验输出目录。测试夹具保留在该目录，不永久删除。

## 特征定义（19 维）

声学分析帧长 1024 样本（64 ms），步长 160 样本（10 ms）；不居中补零。低于 0.4 秒、静音或低有声覆盖段不参与基线和综合分数。缺测值是空白 / JSON `null`。

| CSV 字段 | 定义 / 单位 |
| --- | --- |
| `duration_s` | 段实际时长，秒 |
| `f0_median_hz` | `librosa.yin` 有声帧音高的中位数，Hz；限定 65–500 Hz |
| `f0_range_st` | 有声帧音高 P90−P10，半音；半音为 `12·log2(F0)` |
| `f0_slope_st_s` | 按真实帧时刻对半音音高做线性拟合，半音/秒；先把音高裁到 P5–P95；不足三个点或覆盖不足 0.1 秒为空 |
| `voiced_fraction` | 活跃且估计周期处归一化相关系数 ≥0.60 的帧数 / 总分析帧数；这是启发式门控，不是有声概率 |
| `rms_mean_dbfs` | 帧 RMS 振幅的算术均值转 dBFS |
| `rms_peak_dbfs` | 最高帧 RMS 振幅转 dBFS，不是样本真峰值 |
| `rms_dynamic_db` | 所有帧 RMS 的 dBFS P90−P10，dB；包含停顿影响 |
| `loudness_lufs` | pyloudnorm 的标准 400 ms 块、K 加权与门控积分响度，LUFS；极短/静音为空 |
| `rate_per_s` | 词数 / 段时长，词/秒；字符代理则为字符/秒；含停顿，不是纯发音速度 |
| `word_duration_mean_s` | 词时间戳的平均词时长，秒；只有段级计数时为空 |
| `pause_inside_s` | 段内 ≥150 ms 的词间间隙总长；无词时间戳时用声学静音代理；不含段首/尾静音 |
| `pause_inside_max_s` | 上述段内间隙最大值，秒；没有时为 0 |
| `pause_before_s` | 段首静音加段起点前连续静音，秒；前向上下文最多读 5 秒；与上一段的文字时间间隔无关 |
| `pause_fraction` | 全段低能量时间比例，含首尾静音，用不重叠 10 ms 块及实际末块长度计算 |
| `spectral_tilt_db_oct` | 活跃帧 Hann 窗功率谱均值，在 100–4000 Hz 对 dB 功率与 `log2(Hz/100)` 拟合的斜率，dB/倍频程 |
| `alpha_ratio_db` | 活跃帧平均功率谱的 1000–5000 Hz / 50–1000 Hz 能量比，dB；较高意味着相对高频更多 |
| `spectral_centroid_hz` | 活跃帧平均功率谱的频率重心，Hz |
| `active_fraction` | 帧 RMS ≥活动阈值的帧数 / 全帧数 |

活动阈值为 `max(-50 dBFS, 帧 RMS P95−30 dB)`。这是能量门控，不能分辨声音是讲者、学生、音乐还是噪声。YIN 的候选音高还需周期相关门控；范围边界候选剔除。RMS 的数值下限为 −120 dBFS，以免静音产生无穷值。

## 本课本讲者基线与分数

每次输入视为一节课。只在该输入内，按调用方提供的 `speaker` 分组做稳健基线，不做声纹识别，不跨课存档。缺少说话人标注统一为 `unspecified`，可能混入其他人。合格段要求 ≥0.4 秒、不是静音、有声帧比例 ≥0.10 且活动帧比例 ≥0.20。

每个特征至少有五个合格有效段才计算中位数和 MAD。`z=(值−中位数)/max(1.4826·MAD, 特征单位下限)`，截到 [−6, 6]；音高中位数先转半音再标准化。每个特征的有效样本数、中位数、MAD 和最终尺度保存在 `summary.json`。

尺度下限：音高中位数/音域 0.5 半音，音高斜率 0.5 半音/秒；RMS/响度/频谱斜率/alpha 比 1 dB（斜率为 dB/倍频程）；语速 0.25 单位/秒；平均词长 0.05 秒；停顿 0.15 秒；比例 0.05；时长 0.1 秒；重心 100 Hz。它们是防止零 MAD 和近常量信号夸大偏离的工程参数，未经过真实课堂标注校准。

强调分是下列正向偏离的加权平均：30% 较高音高、30% 较宽音域、10% 较高 RMS、10% 较高 LUFS、10% 段前较长停顿、10% 较慢语速。所有分量均取 `max(0, 方向·z)`，范围 [0, 6]。音高中位数和音域必须有效；其余缺测分量省略并重新归一权重，`score_status=partial_features`。CSV 保留所有原始值和 z 值以便审查。没有足够基线或不合格段的综合分为空，不能用这些段充当“最低强调”。

语速偏离分直接使用语速 z：正值较快、负值较慢、0 为本组常态。分数不是概率，也不意味着一个具体教学重点已被识别。音高斜率、频谱等先作为可审查特征保留，未全部塞进综合分数。

## 现有管线核查

`Scripts/qwen_asr_service.py` 的 `transcribe_parakeet` 访问 `result.sentences` 仅用于计数和置信度一致性，返回 `text` 和置信度，不返回词时间戳。`LiveLingo/Sources/TranscriptSegment.swift` 保存段起止时间和字幕文本，无词数组。**不能把上游模型能产生时间戳等同于 App 已保存词时间戳。**

独立 `Scripts/trigger_eval/collect.py` 会为公开联合国英语口译另存 `*.public-words.jsonl`；其余公开课实验只保存段级 `pk_word_count`。本轮 CS50 分析复用已保存段边界和词数，不重新转写；平均词时长为空，段内停顿使用能量代理。

## 输出、耗时与验收边界

新目录包含 `vectors.csv`、`summary.json`、`highest-10.csv`、`lowest-10.csv`。抽查清单只含开始/结束秒数、强调分和语速偏离分，无文字。CSV 含每段 19 维原始值及对应 z；语速与停顿来源、质量状态明确标记。已有结果目录拒绝覆盖。可选 `distribution.png` 展示整个输入的分数分布及时间轴。

`cpu_s` 是 `time.process_time()` 的进程 CPU 秒，`wall_s` 是真实经过秒数；包含解析、音频读取、依赖首次导入、特征计算和标准化，排除输出、完整输入哈希和画图。`cpu_s_per_audio_hour=cpu_s·3600/音频总秒数`；另给每实际分析音频小时 CPU 秒，避免稀疏分段让开销看起来过低。这是离线 CPU 开销，不是能耗、实时字幕延迟或 App 总资源测量。

合成测试验证全部特征的方向/边界、说话人分组、零 MAD、极端异常值、缺失/拒绝词数、静音/空段/极短段、格式错误及无文字输出。公开课结果只证明程序能运行、产生可抽查的数值，**尚未进行人耳抽查和人工强调标注，不能声称准确率或教学收益。**

下一步先对时间点做人工听审，校准门控/权重，并在有已知说话人范围的公开片段评估。远场、麦克风距离变化、倍频/半频、噪声和学生发言仍会干扰。若继续第二步预训练模型对照，必须先获得用户对具体下载、许可与执行方式的同意；本原型不触发下载或模型推理。
