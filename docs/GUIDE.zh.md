# LiveLingo 0.3.0 中文使用说明

LiveLingo 帮你在听课时看字幕、整理笔记，课后再对照录音复习。0.3.0 支持简体、台湾繁体和港澳繁体中文输出，菜单和按钮仍用简体中文。识别、翻译和笔记都可能有错，重要内容请对照原文和录音。

## 初次打开与保存位置

安装后，从“应用程序”打开 LiveLingo。程序会先检查本机模型；如果“开始记录”暂时不能点击，先看窗口底部的提示，点“状态详情”查看原因。出现“重新检查模型”时，可以点击重试。

打开“更多 → 课堂设置…”，在“录音与保存”中确认“记录方式”。默认是“保存录音与笔记”。点击“选择保存位置…”，选一个用来存放课程的文件夹；也可以从“更多 → 保存位置…”选择。

每次记录会在所选位置新建一个课程文件夹。不提前选位置也可以点“开始记录”，程序会先请你选择；取消选择就不会开始录音。

“实时暂存”适合只看当下字幕。它也会写临时录音，但结束后会删除临时录音并清空这次内容。要保留这节课，请在结束前点“更多 → 转为录音…”，选择保存位置；录音会继续，结束时再保存到那里。

在“课堂设置… → 字幕与处理 → 输出语言”中，可以选择“简体中文”“繁體中文（中國台灣）”或“繁體中文（中國港澳）”，默认简体。选择只对新录音和导入生效，不会改变已经打开的课程。英语、西班牙语和法语输出尚未开放。

已保存的中文课程若有“录音处理… → 阅读文字”，可以在那里切换简繁体显示，无需重新翻译；保存和导出仍用这节课原来选择的语言。

## 选择声音来源与权限

在“课堂设置…”的“音源”中选择声音来源。录音或暂停期间不能切换音源和记录方式；要换来源，先结束这次记录。

- “麦克风”收录麦克风听到的声音，适合教室里的老师发言。
- “系统内录”收录 Mac 上播放的声音，适合网课和视频。它不是麦克风录音，也没有让你只选某一个网课 App 的入口，其他应用播放的声音也可能被录进去。

第一次开始使用麦克风时，按系统提示授权。若拒绝了，到“系统设置 → 隐私与安全性 → 麦克风”允许 LiveLingo，再重新开始。

系统内录需要系统音频录制权限。启动失败时，按提示到“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”允许 LiveLingo，再重新开始。虽然权限名称包含“屏幕”，这条录制流程只接收音频，不保存屏幕视频。

macOS 还可能请求“语音识别”权限，这是给可选的英文逐词预览用的。预览不可用时，程序仍可用内置模型生成正式字幕。

## 开始、暂停和结束记录

点顶部的“开始记录”。准备和授权完成后，状态会变成“录音中”；录音时长和声音波形显示在窗口上方。

需要暂时停下时，点“暂停”；继续听课时点“继续”。暂停期间不会收录新的声音，但之前收下的内容仍可能继续转写、翻译和整理。

使用“保存录音与笔记”时，课后点“结束并保存”。这会停止收音并保存课程，剩余的转写、翻译和笔记可能还在处理。看底部状态确认进度，不要把“已保存”理解为所有内容都已整理完成。

使用“实时暂存”时，按钮是“结束记录”，结束后不会保留这次内容。两种方式结束后，再点“开始记录”都会新建一次记录。

“录音”菜单中也有开始、暂停和结束操作。快捷键为：⌘R 开始或结束，⇧⌘P 暂停或继续。

“课堂设置… → 字幕与处理”中的“录音期间防止空闲睡眠”默认开启，但不能阻止合盖、手动休眠或断电。录音中系统休眠会结束并保存已收到的内容；唤醒后需要主动开始新录音。

## 退出与恢复未完成的录音

录音、暂停或导入时按 ⌘Q，会先询问是否退出。按回车会留在当前课堂或继续导入；选择“保存并退出”才会收尾退出。导入时只保存已经导入的部分。

“实时暂存”也可以选“保存并退出”，将这节课转存为录音；没有保存位置时会先请你选择。取消选目录或保存失败，就留在应用中。选“退出不保存”则丢弃这次临时内容。

退出会等待保存与清理。若失败或约 15 秒没有保存进展，会提示“退出前的保存或清理未完成”，可以选“留在应用”或“仍要退出”；仍要退出可能留下未完成的保存。系统关机、重启或注销时不会先询问，保存录音方式会尝试直接保存，“实时暂存”不会自动转存。

如果“实时暂存”已转为录音，但尚未完整保存就意外退出，下次打开后，“更多 → 恢复未完成的录音”会列出可恢复的记录。选择对应时间恢复，不会继续收音。按提示检查处理与保存状态；若原目录无法访问，用“保存位置…”重新选择。若“录音处理…”出现“重试保存课程进度”，可以点击重试；处理显示暂停时，再按需点“继续处理”。这不是所有意外退出都能恢复的保证。

## 警报提醒

“课堂设置… → 提醒”中的“录音时检测警报声并提醒”和“警报时自动保存本节并另开新录音”默认都开启。只在用麦克风录音时检测，暂停、系统内录和导入文件都不会触发。

持续听到警报声时会出现提醒。保存录音方式下，自动保存开关开启时会倒计时 30 秒，然后保存本节，在同一位置另开带“· 警报后”后缀的新录音。倒计时内可以取消，暂停也会取消倒计时；“实时暂存”只提醒，不自动保存或分段。也可以只关闭自动保存，保留提醒。

悬浮字幕可见时，提醒显示在字幕窗里；隐藏时才发系统通知，首次需要通知时 macOS 会询问权限。LiveLingo 或字幕窗有键盘焦点时，可按 Esc 取消提醒。警报提醒可能漏报或误报，不能代替火警等安全设备，请以现场广播和工作人员指示为准。

## 实时字幕与语种标签

主窗口的“双语转写”显示已识别的内容。英语发言显示英文原文和中文译文；识别为中文的发言只显示中文原文，不重复放一行相同的“译文”。其他受支持语言的发言保留原文，并翻译成中文。

非英语段落旁边会显示较小的语种标签，例如“中文”“日语”或“法语”。它表示这一段识别到的语言；英语段落不额外加标签。标签不属于字幕正文，复制和导出字幕时不会混进文字里。

语种会自动判断，不用手动切换。英语识别不可靠，或前一段可能是其他语言时，程序会再检查语种。法语、西班牙语等需要连续两段确认，只从当前段开始切换；中文等可以单段确认。短句或突然换语言时仍可能认错，不能把标签当作准确率保证。

中文被认成英文时，把鼠标停在那句字幕上，点“…”或右键，选“按中文重新识别”。录音或暂停期间会排队，等课堂结束、实时转写完成后再处理；等待或识别中可以选“取消中文重识别”，完成后可选“撤销中文重识别”。这项操作需要本句完整录音可读；“实时暂存”中不可用，要保留后再改，请先“转为录音…”。

最新字幕在顶部。想回看前面的内容，关闭“跟随最新”，新内容就不会把阅读位置拉回顶部。切到别的窗口看课件时，“跟随最新”仍会更新。可在“更多 → 阅读字号”或“课堂设置… → 阅读字号”选择“标准”“大”“特大”“两倍”，默认“标准”；字幕、笔记、时间戳和公式一起缩放，悬浮字幕在自己的字号基础上缩放。“显示”菜单也有字号操作：⌘= 放大、⌘- 缩小、⌘0 恢复默认。

“同步初译”用于较早看到中文，正式译文随后出现在字幕中；初译还可能变化，不能当作定稿。这个选项在“课堂设置… → 字幕与处理”中，默认开启并记住你的选择，macOS 15 及以上可用。macOS 14 没有同步初译，仍可等待正式译文。

## 悬浮字幕

点主窗口顶部的“悬浮字幕”图标，或选“录音 → 显示悬浮字幕”（⇧⌘F），可以打开一个独立字幕面板。它每次启动都默认关闭，需要时再打开；“开始记录时自动显示悬浮字幕”默认关闭，可在设置中开启。关闭面板不会结束课堂记录。

在“课堂设置… → 悬浮字幕”中可以调整：

- “显示模式”：双语（默认）、仅中文译文、仅原文。“仅中文译文”在译文可用前会先显示原文；中文发言仍显示中文原文。面板顶部也可切换显示模式、暂停或继续录音。
- “原文字号”和“译文字号”：分别调整两部分文字的大小。面板右上角也有“标准”“大”“特大”字号菜单。
- “背景不透明度”：调低后能透过面板背景看到后面的课件。
- “在所有桌面显示”：默认开启，让面板跟随普通桌面的切换；它本身不保证覆盖其他 App 的原生全屏。

切换显示模式不会改变面板高度。没有显示的部分可能留白。点击未锁定的字幕面板不会把你正在使用的课件窗口切到后面。

主窗口“悬浮字幕”旁的锁图标可以锁定面板。锁定后，点击会穿过字幕窗，作用于后面的窗口；此时不能直接点击面板里的普通控制项，警报提醒的取消按钮仍可点击。解锁有三种入口：

1. 回到主窗口，点锁图标“解锁悬浮字幕”。
2. 取消勾选“录音 → 锁定悬浮字幕”；如果顶部菜单栏有 LiveLingo 图标，也可在其菜单中取消勾选“锁定悬浮字幕”。
3. 按 ⇧⌘L 切换锁定状态。这是应用快捷键，只在 LiveLingo 位于前台时有效。

每次重新启动，面板默认未锁定。

面板挡住课件或需要归位时，选“录音 → 悬浮字幕移到屏幕底部”或“悬浮字幕移到屏幕顶部”，它会回到所在屏幕对应的居中位置并显示出来。面板右上角的“字号与位置”菜单也能移动；菜单栏 LiveLingo 图标里也有同名操作。面板会记住上次的位置。

## 全屏网课模式

这个实验性模式默认关闭。需要尝试在其他 App 的原生全屏中看字幕时，到“课堂设置… → 悬浮字幕”开启“全屏网课模式”；也可以从 LiveLingo 应用菜单选“开启全屏网课模式”。开启模式后，仍要按需打开“悬浮字幕”。

开启后，LiveLingo 的 Dock 图标和应用菜单栏会消失，也不再出现在 ⌘Tab 切换列表里。改用屏幕顶部菜单栏的 LiveLingo 字幕图标操作：可以显示主窗口、显示或隐藏字幕、锁定或解锁、调整显示模式和位置、暂停或继续、开始或结束记录，以及退出。普通模式也可单独开启“在菜单栏显示 LiveLingo 图标”，这个开关默认关闭。

全屏网课模式会强制让字幕加入所有桌面。关闭后，恢复“在所有桌面显示”的原设置，并恢复普通应用显示方式。全屏模式的开关会记住，下次启动可能仍处于开启状态。

真机效果以实际为准，不能保证所有全屏网课软件都能正常覆盖。字幕可能挡住系统菜单或通知；遇到遮挡可从菜单栏图标把它移到底部、隐藏，或关闭全屏网课模式。

## 学习笔记与课后复查

字幕逐渐稳定后，“学习笔记”会自动整理课堂内容。宽窗口中笔记在字幕旁边；窄窗口可切换“字幕”和“笔记”。

“最近更新”看最新整理的一批，“整课笔记”看已累计的内容。点笔记标题旁的信息按钮，可以查看整理进度；点“更新”可以请求再次整理。字幕积压或内存紧张时，笔记可能要等待。

课程保存并有可复查的笔记后，点“复查笔记…”，再从“复查…”选择整课、最新一批或指定批次。复查使用本机较大的 9B 模型，耗时随设备和内容变化。

复查结果在“核对意见 · 正文已保留”中单独展示，不会自动改写笔记正文。把它当作复习时的核对提示；遇到不确定的知识点，仍要回听录音、看字幕。

“管理队列…”可以查看复查任务、重试失败项和调整顺序。开启“专注模式”时，录音与字幕优先，后台复查等待空闲。

## 导出与再次打开课程

在“学习笔记”下方点“导出”，选择 Markdown、纯文本、Word 或 PDF，以及“最近更新”或“整课笔记”的范围。按需勾选“附带双语字幕与时间戳”和“附带核对意见”，再点“选择位置并导出…”。

附带字幕按所选笔记范围导出；核对意见是这次录音已有的复查报告，作为独立章节，不随“最近更新”缩到一批。导出只读取当前结果，不会调用模型替你重新整理。所选范围没有笔记时，会提示无法导出。

课程文件夹里还会保存录音、字幕文本和字幕文件；笔记生成后也会保存笔记文件。结束后可从“更多 → 在访达中显示”查看。请保留整个课程文件夹，以便恢复处理进度。

以后选“更多 → 打开课程…”或“文件 → 打开课程…”，选择那节课的文件夹。打开旧课不会重新录音。若仍有未完成的处理，可在“更多 → 录音处理…”中查看状态、暂停或继续处理。

要处理已有音频或视频，选“更多 → 导入音频或视频…”（也在“录音”菜单中，⇧⌘I），选择文件和课程保存位置。导入不会改动原文件；“停止导入”会保留已经导入的部分。

用 0.3.0 实时录制或含新内容的课程，以及在 0.3.0 中继续处理过的旧课，0.2.0 可能打不开，但不会改动原文件。若可能退回旧版，请先复制课程文件夹。打开旧课后点“开始记录”会另开一节，不能接着旧录音继续收音。

Word、PDF 导出目前会丢掉笔记的列表符号，正文仍保留；需要保留列表格式时可用 Markdown。笔记导出中按 ⌘Q 不会等待导出，请等导出完成再退出。

## 数据与隐私

正式转写、翻译、笔记和复查在本机处理，没有把课堂录音上传到云端推理的入口。保存的课程文件夹和导出文件可能包含老师、同学的发言；分享前请检查内容。

“实时暂存”也使用临时录音，不能理解为从未写入硬盘。它在正常结束或退出时删除临时录音；强制退出或崩溃后可能仍有文件保留。若界面报告清理失败，请按提示检查。

更多说明见[隐私说明](PRIVACY.md)。

## 常见问题

### 翻译停住了怎么办？

先看底部“状态详情”，区分音源、识别和翻译的状态。若显示“已暂停”，点“继续”；若本机模型未就绪，点出现的“重新检查模型”。只有初译停住时，可以关闭“同步初译”，继续看正式字幕。

如果个别段落提示翻译未完成，原文会保留，程序对部分失败会自动重试。课后仍缺译文时，打开“录音处理…”，若处理已暂停就点“继续处理”；若仍没有恢复，可先“暂停处理”，再“继续处理”，重新排入未完成的翻译。这不会补录停止后的声音。

### 笔记整理失败或迟迟没有更新怎么办？

看笔记标题旁的信息按钮里的状态。如果在等字幕或内存，先让当前字幕处理完成；已有笔记会保留。出现“本轮更新失败”时，可点“更新”重试。若课后处理已暂停，先在“录音处理…”中点“继续处理”。重试仍可能失败，请保留课程，不要把空白或旧笔记当作已整理完成。

### 磁盘空间不足会怎样？

录音会持续写到硬盘，课前请确认保存位置有可用空间。“实时暂存”也需要空间。音频写入失败可能使录音停止；课程进度或导出文件写入失败也会有提示，不能据此认为整节课已完整保存。

先保留现有课程文件，处理空间问题，再看界面提示。如果“录音处理…”中出现“重试保存课程进度”，可以点击重试；保存成功后处理可能仍保持暂停，需要另点“继续处理”。若提示录音已经停止，后面的声音没有收录，重新点开始会新建记录。

### 第一次打开必须联网吗？

不需要。0.3.0 的公证票据已经装订在 App 和安装包里，第一次打开时 macOS 可以断网完成安全检查（会显示“正在验证”，然后询问是否打开从互联网下载的 App）。

完整离线安装包中的正式转写、翻译和笔记模型不需要联网下载。若提示内置模型或运行时缺失，联网本身不会让程序自动补齐，请确认安装包完整。

可选的英文逐词预览和“同步初译”还依赖 macOS 的系统资源。首次准备初译时，程序会请系统准备语言包；如果系统要求下载，需要联网完成这一步。也可以关闭“同步初译”，等待本机模型的正式译文。英文逐词预览资源不可用时，程序会退回稳定字幕模式。

### 结束录音后为什么还在处理？

“结束并保存”先停止收音、保存现有进度，再继续处理已经收下的内容。可以在“录音处理…”中暂停处理，之后再继续。处理完成前导出的文件只包含当时已有的结果。
