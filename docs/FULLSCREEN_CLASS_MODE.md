# 全屏网课模式

此功能默认关闭。在“设置 → 悬浮字幕”开启，或在 LiveLingo 的 App 菜单选择“开启全屏网课模式”。开启后 Dock 图标和 App 菜单栏消失，⌘Tab 中也不再出现；用顶部菜单栏的 LiveLingo 字幕图标操作。关闭模式后恢复 Dock 和 App 菜单栏。

顶部图标的菜单可显示主窗口、显示或隐藏浮动字幕、锁定或解锁字幕、将字幕移到当前屏幕底部、开始或结束记录、关闭模式，以及退出。录音命令与主窗口共用；保存模式显示“结束并保存”，实时暂存模式显示“结束记录”。记录中图标带红点，暂停时带橙点，并提供中文无障碍状态。锁定后字幕点击穿透，仍可从顶部图标解锁。⌘⇧L 仅在 App 位于前台时有效。

模式开关会保存。下次启动时，若仍开启，App 在启动阶段切为 accessory，显示顶部图标和主窗口。字幕可见与锁定状态不保存，每次启动仍需手动显示字幕，默认未锁定。模式开启时强制加入所有桌面，关闭后恢复“在所有桌面显示”原来的设置；不修改该偏好。

## 层级与证据边界

实现使用自管 `.nonactivatingPanel` NSPanel、`.accessory` 激活策略，以及 `.canJoinAllSpaces`、`.fullScreenAuxiliary`、`.canJoinAllApplications`。SDK 的 NSWindow 说明要求互斥的窗口角色不能混用，因此应用时移除不兼容角色，恢复时使用保存的原值。

层级集中在 `FloatingSubtitleWindowSettings.fullScreenLevel`，目前选 `.screenSaver`。依据是派单提供的 [Apple DTS thread 826308](https://developer.apple.com/forums/thread/826308) 本地审查记录：`.floating`、`.statusBar` 不能覆盖其他 App 的全屏内容，DTS 示范成功配置使用 `.screenSaver`。这是现有证据中有成功依据的层级，**没有证明它是数值上最低可用的层级**。本次没有联网重读论坛，也没有实测其他 App 的全屏空间。

高层级可能遮挡系统菜单或通知；建议将字幕移到屏幕底部，必要时隐藏。全屏模式会将字幕限制在所在屏幕顶部菜单栏及刘海的下方，预留全屏菜单栏的显露区域，避免挡住顶部操作图标；拖到顶部时会向下移回。LiveLingo 的顶部菜单展开时暂时将字幕降回 `.floating`，关闭菜单后恢复模式层级，以便使用解锁、关闭和退出入口。菜单展开期间，全屏中的字幕可能暂时不可见。其他系统界面不会由此自动降级。

切换前保存主窗口的可见与焦点状态，切换后立即恢复，并在下一轮主线程事件循环再恢复一次；快速切换或退出会使过时的恢复动作失效。开启时不主动夺取原本属于其他 App 的焦点，关闭时请求激活 App。状态栏创建或激活策略切换失败时显示错误，不保存失败的开关值。真正退出时移除状态栏项、关闭字幕、恢复窗口原始属性与启动时的激活策略，保留模式偏好。

## 真机确认清单

1. 主窗口可见且有焦点时开启模式：确认窗口仍可输入，Dock 与 ⌘Tab 中的 LiveLingo 消失，顶部图标出现。连续开关几次后确认焦点和图标都正确。
2. 显示字幕，分别将 Zoom、腾讯会议和浏览器切为原生全屏：确认字幕可见；切换桌面、退出并重新进入全屏后再次检查。记录使用的 macOS 版本和 App 版本。
3. 在其他 App 全屏时点击未锁定字幕：确认没有把网课带离全屏空间。锁定字幕后点击同一位置，确认点击落到下方 App；从顶部图标解锁。
4. 在顶部菜单中依次显示/隐藏字幕、移到底部：确认标题同步，字幕落在原所在屏幕的可见区；在副屏、不同屏幕排列、Dock 位于左/右/下时复查。
5. 在已有授权的录音环境中从顶部图标开始、结束记录，并在主窗口暂停：确认主窗口和菜单标题同步，记录中红点、暂停时橙点正确，结束后恢复普通图标。保存记录与实时暂存分别检查结束动作。
6. 将字幕放到系统菜单或通知附近：检查是否遮挡；展开 LiveLingo 顶部菜单确认解锁、关闭与退出项可操作，关菜单后字幕恢复。遇到遮挡可移到底部或隐藏。
7. 从顶部图标关闭模式：确认 Dock、App 菜单与 ⌘Tab 恢复，主窗口可激活；“在所有桌面显示”原值以及锁定状态不被切换改写。
8. 保持模式开启退出再启动：确认启动即隐藏 Dock，顶部图标和主窗口可见，字幕默认关闭且未锁定。关闭主窗口后从顶部图标重新显示；退出后确认没有残留图标或字幕。

自动化测试只证明控制器路由、状态、窗口属性和离屏布局。它不会切换测试宿主激活策略，也不证明 Zoom 等 App 的全屏效果、系统焦点转换或真实菜单跟踪行为。
