# 中文地区用语

语言名称写法是项目命名规范：简体中文、繁體中文（中國台灣）、繁體中文（中國港澳）。两种繁体已在开发源码开放。英文、西班牙文、法文的开放状态及生成规则不因本次改动改变。

用语经大模型审阅，非母语者人工审校。审阅者为执行本任务的 Codex 会话大模型，依据公开用语资料逐条审阅；未调用本地模型。样本为 356 句合成课堂文本，包括 150 个表项正反例、160 个独立课堂情境和 46 个技术边界变体。重复句式不等于同等数量的独立语言情境，也不构成真实课堂准确率或母语者认证。

共 75 条，其中 24 条为同词保留，51 条实际替换。每条前面的注释有学科、审阅者、出处网址和具体词目／章节；SOURCE.json 锁定项目表哈希。先做不变的上游 s2tw/s2hk，再在同一遍中优先匹配学科覆盖表、其次通用表，替换结果不重复转换。技术片段先隔离，代码、公式和 JSON 键保留原字节。

| 学科 | 台湾示例 | 港澳示例 | 保留与边界 |
|---|---|---|---|
| 物理 | 标量→純量；矢量→向量 | 標量、矢量 | 速率与速度不合并；比熱容、比熱容量都保留 |
| 化学 | 电离能→游離能；电离常数→游離常數 | 電離能；稀有气体→貴氣體；原子序数→原子序 | 活化能保留；只替换有出处的完整术语 |
| 数学 | 概率→機率；正态分布→常態分布 | 概率、函數 | 数学函数不一概转成函式；變量→變數 |
| 计算机 | 軟體、硬體、資料庫、位元組、程式設計 | 軟件、硬件、數據庫、程式編寫 | 电脑复合词限定语境；个比特→個位元，不改名称中的比特 |
| 生物 | 线粒体→粒線體；酶反应→酵素反應 | 線粒體、酶反應、細胞器 | 不全局改“酶”，保留聚合酶等复合名称 |

不收函數→函式、對象→物件、文件→檔案、程序→程式、數據→資料这些无语境的宽泛替换。电脑的完整复合词可转换，例如資料庫檔案、程式設計；研究对象、实验程序与观测数据保留学科含义。特征值、负权环、菲利普斯曲线、地名和人名的地区别称没有在本表中另立未核实规则；基础字形转换仍使用上游词表。台湾地理例有出处的悉尼→雪梨、新西蘭→紐西蘭；程式中的同名标识符保留。港澳档案采用香港教育局书面教学术语，不声称验证了澳门专有用语或粤语口语。

## 存档与验证边界

固定课堂文字随内容转繁体。中文三种之间只切换阅读显示，不改课程 targetLocale、生成请求或导出目标；bilingual.jsonl 保留简体底稿，繁体课程沿用 schemaVersion 1。新课程和导入选择器开放三种中文，忙碌时禁用；旧课程仍读自己的快照，不读新课程偏好。已是繁体的旧 Markdown 不二次转换。

转换器为 `opencc-ver.1.1.9+livelingo-v2`，上游字典版本不变。核对器严格拒绝其他转换版本的现成导出；v1 导出可用原版本核对，或由保存的简体底稿重新导出，不能把两个版本的字节视为相同。本次核对本版的 schemaVersion 1 文件与 CLI 往返，保持原有 0.2.0 兼容设计；未运行 0.2.0 二进制、GUI 或任何 VM。App 中的 LICENSE、NOTICE 和 SOURCE.json 在构建后核对；没有生成 DMG、更新已安装 App 或公开发布。
